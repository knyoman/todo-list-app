# 📝 To-Do List App

Sebuah aplikasi To-Do List sederhana berbasis web. Proyek ini pada awalnya dibangun sebagai sarana latihan kolaborasi tim menggunakan alur kerja Git (Branching & Pull Request) serta implementasi fundamental web development.

## ✨ Fitur

*   **Tambah Tugas:** Memasukkan target atau pekerjaan baru ke dalam daftar.
*   **Hapus Tugas:** Menghilangkan tugas yang sudah diselesaikan menggunakan tombol interaktif.
*   **UI/UX Sederhana:** Antarmuka yang bersih dan fokus pada fungsionalitas.

## 🛠️ Teknologi yang Digunakan

*   **HTML5:** Struktur dan kerangka halaman web.
*   **CSS3:** Desain, tata letak, dan styling antarmuka.
*   **Vanilla JavaScript:** Logika interaktif (DOM Manipulation) tanpa framework tambahan.

## 🚀 Cara Menjalankan Proyek

Ikuti langkah-langkah berikut untuk menjalankan aplikasi ini di komputer lokalmu:

1.  **Clone repositori ini:**
    ```bash
    git clone https://github.com/username-kamu/todo-list-app.git
    ```
2.  **Masuk ke direktori proyek:**
    ```bash
    cd todo-list-app
    ```
3.  **Jalankan aplikasi:**
    Buka file `index.html` secara langsung menggunakan browser web (Chrome, Firefox, Safari), atau jalankan menggunakan ekstensi *Live Server* di Visual Studio Code.

## 🤝 Panduan Kontribusi (Workflow)

Proyek ini menggunakan standar kolaborasi *open-source*. Jika kamu ingin berkontribusi, ikuti alur berikut:

1. Lakukan **Fork** pada repositori ini.
2. Buat *branch* khusus untuk fiturmu (`git checkout -b fitur-keren-kamu`).
3. Lakukan *commit* pada perubahan kodemu (`git commit -m 'Menambahkan fitur keren'`).
4. *Push* ke *branch* tersebut (`git push origin fitur-keren-kamu`).
5. Ajukan **Pull Request** ke *branch* `main`.
